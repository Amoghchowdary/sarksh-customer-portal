# Google Sheets Database Schema

The `setupSarksh()` Apps Script function creates these tabs:

1. 01_USERS
2. 02_CUSTOMERS
3. 03_ADMINS
4. 04_ROLES
5. 05_SESSIONS
6. 06_KYC
7. 07_KYC_DOCUMENTS
8. 08_TRADES
9. 09_ACCOUNTS
10. 10_LEDGER
11. 11_NOTIFICATIONS
12. 12_AUDIT_LOGS
13. 13_SYSTEM_LOGS
14. 14_BACKUPS
15. 15_SETTINGS

**Operating principle:** the Sheet is the data layer. Administrators should use the Admin Control Centre for normal operations.
